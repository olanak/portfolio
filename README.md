# Olana Kenea Lemesa — Cyber Portfolio

Interactive infrastructure & cloud-security portfolio with blog system and secret admin dashboard.

## ✨ Features

### Public Portfolio
- **"Control plane" dark theme** — deep slate surfaces, blueprint grid, cyan + emerald signal accents
- **IAM-flavored hero** — animated terminal line plus a signed `access-policy.json` panel
- **Well-organized sections** — Profile → Focus areas → Capabilities matrix → Experience → Credentials → Work → Writing → Contact, each numbered and clearly grouped
- **Framework band** — NIS2, DORA, EU AI Act, ISO 27001, NIST CSF and CIS at a glance
- **Scroll-triggered reveals** — restrained staggered animations, no heavy effects
- **Animated counters** — hero stats count up when they enter the viewport
- **Filterable, expandable project cards** with problem / approach / outcome detail
- **Smooth single-page navigation** with fixed nav and mobile menu

### Blog & Admin
- **Series-aware blog** — multi-part build journals with prev/next navigation
- **Secret admin dashboard** — type `admin` anywhere to open it; edit all content, then export `data.js`
